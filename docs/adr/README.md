# Mimari Karar Kayıtları (ADR)

ayrı bir dosyadır ve numarası değişmez. Kararlar silinmez; değişen bir kararın
yerine yenisi yazılır ve eskisinin durumu "Yerine geçildi: ADR-XXXX" olur.
